# 智演安巷

“智演安巷”是面向老旧小区消防应急演练的数字孪生与具身智能体平台。当前 Beta 已打通“社区底图—场景设计—决策任务—演练总控—机器人执行—事件证据—评分回放—方案对比”的主案例闭环。

## 已实现功能

本轮交付与测试范围见 [开发验收记录](docs/开发验收_2026-09-06.md)。开发服务入口为 `http://127.0.0.1:5173/projects`。

- 地图、场景、导演台使用独立 URL；刷新保留社区、场景与场次，浏览器前进后退可用。
- 场景草稿切页有未保存提醒，参数试算失败会明确标注仍显示上一次结果。
- 三维住宅补充立面、屋顶和设备细节，静态消防车、救护车与小汽车模型在本地加载；首页展示图来自本系统渲染。
- 生产环境采用 history 路由，静态服务器须将不存在的前端页面路径回退到 `index.html`，但 `/api/` 与实际资源请求不能走该回退。Vite 开发服务已支持页面回退。
- 前端验证：`cd frontend` 后运行 `npm test`、`npm run build`。

### 本轮：连续空间训练（新建场次 V3）

刷新导演台后，旧场次点击「新建连续空间训练」；结束的场次也可点击「新开一轮」。历史数据不清空、不迁移演练模型。

1. 场景参数中设置人口、水源、南门通道与示例楼梯净宽，保存后预览；新场次使用同一冻结模型。
2. 左侧「指挥」选楼层／个人，或「三维框选」拖动选择；点击出口或北／南路线按钮预览，确认后才下令。
3. 三维剖面按服务端 x/y/height 显示房间、走廊、楼梯、楼门与室外行走；展开「逐人跟随与队列」查看最后位置、累计等待并跟随。
4. 「清点」只允许已到集合点的人核验；未到名单显示最后位置，可指定搜索责任人。搜索员实际沿通道到达，会合后居民恢复撤离。
5. 「重做」选择具体决定之前创建暂停分支，点击继续后改派路线。对照原训练的同一已发生时刻，查看双三维现场及每位居民的暴露／排队差值。

这是示例户型的训练模型，不是实测建筑或安全认证。间距约束作用于同一通道车道，交汇节点采用简化合流，不是全局刚体碰撞／高精度人群动力学。

### 原有基础能力

- 开发环境登录、健康检查、JWT 鉴权和账号数据隔离。
- 社区项目、版本、八类地图对象、道路节点/边、通行状态及可达性检查。
- 一键生成“夜间电动自行车充电棚火灾”示例社区。
- 场景模板、参数配置、0–10 分钟规则化火势/烟气预览、决策点与任务生成。
- 场景完整性校验、草稿/发布状态机和已发布场景管理。
- 演练场次、四类角色、服务端统一时钟、开始/暂停/继续/结束状态机。
- WebSocket 实时快照、处置任务、动态事件注入和不可变事件流。
- 巡检广播机器人感知—复核—上报—执行状态机、风险改道、轨迹与原因展示。
- Three.js 离线三维社区沙盘，支持建筑/设施选择、旋转缩放、总控/机器人/居民/救援四视角。
- 新场次冻结地图、道路、火点、任务和人口参数；主案例为 60 名居民，旧场次继续使用原模型。
- 火焰与烟气规则演化、重点人员差异化速度、护送员会合及共同撤离、连续烟气暴露与路段拥堵。
- 可将通道堵塞、水源失效、人员失联事件拖入沙盘，直接改变道路、机器人路线和疏散状态。
- 双视图规则预测：从实时或指定历史时刻，比较两套既定出口策略的疏散、暴露和预计得分；不是可自由编辑的两个独立世界。
- 手机身份登记与责任任务：接收、回执到位、处置计时、核验证据，角色绑定，重复提交幂等。
- 后台自动巡检、连续三次近场采样确认火情、任务触发和超时事件；自动事件导演不再依赖浏览器定时器。
- 证据关联评分、优化建议、时间轴回放、复盘 JSON 导出和多场次对比。
- 一键清空演练记录；地图、场景和决策配置保持不变，可连续重复演示。

## 本地启动

### 标准方式（PostgreSQL）

1. 在项目根目录执行 `copy .env.example .env`。
2. 执行 `docker compose up -d db` 启动 PostgreSQL。
3. 进入 `backend`，创建虚拟环境、安装 `requirements.txt`，执行 `uvicorn app.main:app --reload --port 8000`。
4. 进入 `frontend`，执行 `npm install` 和 `npm run dev`。
5. 打开 `http://127.0.0.1:5173`。

### 无 Docker 的本地预览（SQLite）

在启动后端前设置：

```powershell
$env:DATABASE_URL='sqlite+pysqlite:///D:/huawei/Documents/work1/tmp/demo-runtime.db'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

SQLite 仅用于本机演示和自动化测试，正式部署仍使用 PostgreSQL。

开发环境默认账号：`admin`，密码：`Zhiyan@2026`。正式部署前必须替换 `.env` 中的账号密码和 JWT 密钥。

## 推荐演示流程

### 第一次使用：引导演练（默认）

进入“演练中心”，有历史场次时先“新开一轮”，然后点击左侧“开始引导演练”。无需手机，也无需记住右侧菜单顺序。

1. 阅读“现在该做什么”：机器人巡检并连续采样，居民在楼内等待通知。
2. 按提示完成断电任务的接收、到位回执和文字核验。回执仅属于模拟演练。
3. 点击“安排 3 名重点居民接应”；再按提示派机器人到入口，到达后广播。
4. 在“从楼内到出口”观察楼层圆点下行，也可以点击“三维楼内示意剖面”。新场次模拟通知、准备、楼梯排队、楼门通行、室外行走，居民不再一开始全部站在室外。
5. 下方可指挥指定居民或普通居民组向北/南门撤离。“试试封路与改道”用于制造训练扰动，不是现实处置建议；解除封锁后继续观察。
6. 查看“刚才的决定”了解结果，回看决定之前的状态；结束后查看未核验任务和未撤离人数。比较按钮是既定出口策略的规则预测；“重新训练一次”从头建立新场次，不是从历史点恢复可编辑世界。

楼层剖面是示意模型：每层用规则行程、准备时间和容量控制下行，没有真实房间图、实测楼梯、连续碰撞避让或室内烟气分层。护送员在入口接应，不模拟入户救援。以上阶段仅新建场次启用，旧场次仍按冻结的原输入回放。

### 自由导演模式与多人演示

顶部可随时切换“自由导演模式”，保留原有全部工具：

1. 登录后生成主案例示例社区并进入地图。
2. 打开“场景草稿”，创建充电棚火灾场景，保存参数。
3. 配置决策点、执行一个决策选项生成处置任务，完成校验并发布。
4. 返回项目登记，进入“演练中心”，创建场次并开始。
5. 等待机器人沿路到达火点附近并连续采样三次；任务栏出现断电、入口广播和重点护送任务。
6. 打开“参演”复制链接到手机，登记物业身份，接收断电任务、回执到位，等待 8 个演练秒并填写至少 6 字证据提交；模型火势增速随之降低。导演可显式代办，证据中记录代办身份。
7. 在任务栏定位入口广播目标并派机器人前往；到达后点击广播，再核验广播任务。普通居民开始撤离。提前选择居民 03、08、15 下达“重点人员护送”，观察蓝色护送员前往会合、共同撤离；全部到出口后才能核验护送任务。
8. 使用“封锁道路”点击具体路段，观察路径变化；选中已封锁路段可解除封锁。普通居民可多选并指定北门/南门。地图点选困难时可使用右上角对象导航。
9. “对比”比较两套既定策略；拖动底部时间轴可回到处置前，再从该时刻预测，未来事件不会提前生效。
10. 结束并评分，点击评分证据查看对应历史现场，或导出 JSON。重演优先使用“新开一轮”，不必清空历史。

## Beta 边界

- 火势与烟气为可解释的规则模型，不是 CFD 高精度仿真。
- 机器人为软件虚拟智能体；手机/实体小车 MQTT 接入属于可选扩展。
- 加入码允许选择初始演练角色，登记后凭证绑定身份；不是组织账号认证。到位和断电证据为演练回执，不是 GPS、摄像头或真实电气设备核验。
- 后台调度及命令锁以单进程为边界，未验收多 worker 集群或 30 台实体手机负载。规则回放按事件重新计算，长场次/大量客户端仍需快照缓存和性能治理。
- 新建 V3 场次具有示例房间—走廊—楼梯—楼门—室外—集合点通道图；不包含 BIM/GIS 导入或真实传感器接入。机器人仍使用室外路网，建筑尺寸、通道宽度与速度需实测标定。老场次按冻结版本重放。
- 护送为虚拟人员模型，重点护送入口限制重点居民及最多 4 个并行对象；尚未提供真实人员排班/资源回站调度。
- 三维模块构建仍有约 738 kB 未压缩包体积提示；低配置设备性能尚待专项压测。
- 复盘导出为结构化 JSON，适合后续接入 PDF 报告模板。
