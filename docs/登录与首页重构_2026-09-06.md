# 登录与首页重构

## 范围与方向

模式：Operate。沿用品牌绿与现有令牌；替换登录和首页的宣传式布局，不修改三维导演台、地图编辑器或后端数据模型。

用户要求选择真实网站参考并直接实现。选用 Linear 项目工作空间与 Mapbox Studio 的任务优先结构，自行实现页面，不复制其品牌或专有源码。

- 登录：左侧品牌、账号表单、服务状态；右侧授权社区摄影与简短产品说明。手机优先显示完整登录表单，参考影像置后。
- 首页：工作空间侧栏、项目列表、右侧示例训练。移除巨型宣传卡片、重复引导和装饰性指标。
- 所有项目名称、数量、地址、状态、版本与更新时间来自现有 API。
- 保留搜索筛选、新建社区、编辑地图、演练中心、示例生成及退出登录。
- 使用说明可展开，侧栏入口会展开并聚焦内容；按钮保留加载、错误与禁用状态。
- 图片授权与出处见 frontend/public/assets/entry-sources.md。

## 验收

前端 `npm run build` 与现有 4 项 API 客户端单元测试通过。

新增 `frontend/tests/entry-pages.e2e.mjs`，实测通过：

- 真实开发账号登录、密码显示/隐藏、退出清除令牌、刷新保留有效会话。
- 实际社区读取、搜索无结果及清除筛选、状态筛选。
- 实际地图和演练中心路由跳转（不代表本轮重新验收其内部仿真功能）。
- 手机使用说明展开并聚焦；创建表单首字段聚焦；取消后返回新建按钮。
- 拦截模拟错误密码、创建失败、案例加载失败及健康检查断网；验证错误提示、输入保留、按钮恢复与重新检查。
- 320、390、768、1024、1440、1920px 宽度检查，登录与首页控件无横向越界；桌面/手机截图已检查。
- 无未捕获浏览器异常。测试没有向用户数据库新增验收社区；新建成功的数据库写入链路沿用既有实现，本轮未重新写入验证。

截图位于 `.tmp/entry-review/`。运行脚本需配置测试账号 `QA_PASSWORD`，可选 `QA_USERNAME`、`QA_BASE_URL`、`PLAYWRIGHT_MODULE`、`QA_BROWSER_PATH`、`QA_ARTIFACT_DIR`；没有将密码写入测试文件。

自我核验依据是代码与测试，不把 Grill Me 访谈技能冒充自动代码评审。Impeccable 的设计检测脚本报告设计选择流程未闭合，结果不能作为通过证明；使用独立截图审查补充判断。

独立审查结果：**Ship**。复核了 1440px / 390px 的登录与首页四张截图，没有发现可见的重叠、横向裁切、主操作不可达或异常文字换行。范围限制：该独立审查没有运行浏览器或独立重跑测试，也没有测量对比度；不是对全系统功能的验收。首个审查代理容量不足，重试审查成功。文档代理容量不足，表面规范由主代理据最终代码补录，没有替换全局 DESIGN.md。
