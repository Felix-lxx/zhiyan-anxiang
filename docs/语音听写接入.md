# 讯飞语音听写接入

接入产品为讯飞“语音听写大模型（中英）V1.0”，使用官方 `wss://iat.xf-yun.com/v1` 协议，提供语音转文字。它与场景问答模型分别配置。

## 使用

在导演台打开“安巷指挥助手”，在“场景对话”或新建“目标计划”中点击“语音输入”。允许麦克风后开始录音，点击“结束并识别”，最多录制 30 秒。结束后音频经本系统后端发送至讯飞，转写文字追加到当前输入框，由用户编辑并确认发送或生成方案。语音转写不会直接执行演练指令。

取消录音不上传音频；关闭助手或切换视图会释放麦克风。已发送给供应商的音频可能已被处理，取消等待不能撤销此前已发生的服务调用。

浏览器麦克风要求 HTTPS 或本机 `localhost` / `127.0.0.1`。手机访问普通 HTTP 局域网地址时不可使用麦克风，需要为平台提供可信 HTTPS。录音需要浏览器支持 AudioWorklet。

## 配置

在被 Git 忽略的仓库根目录 `.env` 中设置，修改后重启后端：

```dotenv
SPEECH_PROVIDER=xfyun_iat_v1
SPEECH_APP_ID=<控制台 APPID>
SPEECH_API_KEY=<控制台 APIKey>
SPEECH_API_SECRET=<控制台 APISecret>
```

停用时设置 `SPEECH_PROVIDER=disabled`。Docker Compose 已转发上述环境变量，需要重新创建后端容器以应用修改。后端直接依赖 `websockets`，与现有 Uvicorn 使用的协议库共用。

密钥和签名 URL 均不返回浏览器；音频只在内存中处理，不写入项目数据库或文件。供应商的数据处理和计费以账号及服务条款为准。

## 协议与错误处理

- 浏览器将录音重采样为 16kHz、16 位小端、单声道 PCM。
- 后端限定 `audio/pcm`、0.25–30 秒、最多 960000 字节；需已登录，限制同账号并发和请求频率。
- 后端采用 HMAC-SHA256 鉴权，按 1280 字节／40ms 分帧发送，处理首帧、中间帧、结束帧及 Base64 结果。
- 动态修正结果按 `sn`、`pgs`、`rg` 合并，避免把被替换的文字重复追加。
- 上游错误、超时、无识别内容和上传过大分别提示，不返回供应商原始错误体或包含密钥的连接 URL。
- 音频识别结果经过用户确认后才进入现有问答或目标规划；超过输入字数上限时需编辑缩短。

接口：`GET /api/v1/speech/status`、`POST /api/v1/speech/transcribe`。录音识别返回文字、供应商标识和音频时长，不改变演练状态。

## 本轮验证

后续界面已加入录音进度、提交互斥、知识检索语音、对话目标接续及主动浏览器朗读。实现和验证见[约束规划与语音工作区升级](2026-11-03-约束规划与语音工作区升级.md)；朗读使用浏览器声音，不是新接入的讯飞语音合成服务。

真实讯飞服务：使用本地授权凭据完成 WebSocket 鉴权握手；该检查未上传音频，不代表已验证账号的听写额度、语音效果或完成一次真实转写。

后端协议和接口回归覆盖签名、结果替换、帧序号及音频还原、认证和输入限额。浏览器验收使用真实 AudioWorklet、合成麦克风设备和隔离转写响应，验证 390px、1366px 布局、PCM 上传、原有输入保留、取消录音及不自动发送。隔离文本不能作为供应商实际识别效果的证明。

本轮 5 项后端语音检查、61 项前端既有检查、类型检查与生产构建通过；浏览器另确认关闭助手停止麦克风、拒绝权限时提示可重试。录音时长同时在音频处理线程和服务端限制，避免后台标签页计时器降频导致无限积累音频。

协议来源：[讯飞 V1.0 官方文档](https://www.xfyun.cn/doc/spark/spark_zh_iat.html)。当前官方页面提示 V1.0 面向历史已开通用户；账号需具备对应能力，不能仅凭密钥格式判定可调用。
