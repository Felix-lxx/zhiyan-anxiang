# 训练档案、对话与经验审核

## 结束后保留什么

结束命令在同一事务中冻结成绩、生成原始档案与经验草稿；归档失败则结束操作回滚。失败、低分及未使用智能体的训练同样保留事实。

档案记录冻结场景、模型修订、成绩、全体人员结束位置与状态、到场清点、护送、暴露及首次越阈时刻、责任任务证据、设备和剩余火情。原始事件继续由事件流保管；档案包含有界关键事件摘要与完整序号范围，不是视频或逐帧录制。

启用社区夜班时，额外保存住户通知状态、回执、到户核查和岗位执行事实，以及未确认户数、尚未结束的核查数量。确认通知不能替代实际到场、清点或责任任务完成。

复盘右侧可下载 JSON 或打开经验草稿。历史场次通过明确的补建操作生成档案，保留原成绩并标记 `historical_reconstruction`；未知旧模型修订不补造。

## 从记录到知识

原始档案不可被经验正文编辑覆盖。经验经组织者核对、审核发布后才进入授权检索；停用、过期或未发布时不作为正常检索结果。删除未发布经验不删除档案，也不会因重复读取自动重建已删除草稿。

智能体的预测—观察对照与全场原始档案分别保存。条件相似不代表单次结果可以外推为策略收益，检索保留差异和缺项。

## 助手对话

问题、回复、引用与观察时刻按场次和账号保存，支持游标分页。清空仅影响当前账号的本场对话，不删除事件、成绩或经验。每次清空提升 `generation`，清空前的迟到模型回复不能重新写回。请求编号与内容冲突、过期代次返回 409。

## 接口和模块

接口前缀为 `/api/v1`，均校验场次访问权限：

| 接口 | 行为 |
| --- | --- |
| `GET /drills/{id}/archive` | 只读；无档案返回 `archive: null` |
| `POST /drills/{id}/archive` | 显式补建已结束训练，重复调用返回原档案 |
| `GET /drills/{id}/assistant/conversation` | `limit`、`before` 有界分页 |
| `DELETE /drills/{id}/assistant/conversation?generation={n}` | 清空当前账号的本场记录 |
| `POST /drills/{id}/assistant/chat` | 保存问答；支持请求编号与代次 |

`training_archive.py`、`assistant_conversations.py` 和 `models/training.py` 分别负责冻结、对话和持久化。新增表为 `drill_archives`、`assistant_conversations`、`assistant_exchanges`，启动时初始化；不批量重写历史成绩或自动发布经验。

验证与剩余项见 [最新验收](../reports/2026-11-10-acceptance.md)，升级流程见 [部署](../operations/deployment.md)。
