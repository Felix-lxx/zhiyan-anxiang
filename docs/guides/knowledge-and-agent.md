# 知识库与智能体

## 完整操作链

首页“知识与预案”维护资料；导演台“安巷指挥助手”使用资料。资料上传、发布与检索有独立状态，检索命中不等于行动合法或已经执行。

1. 选择社区与厨房/充电棚案例，输入资料正文或上传支持的文件。
2. 查看实际提取内容、来源、版本、适用范围和有效期。
3. 提交审核并发布；草稿、停用、过期及无权限资料不进入正常检索。
4. 助手读取授权资料及本场权威状态，引用定位到具体版本和片段。
5. 目标计划读取现场、路线和资源工具，生成不同动作的候选，限时仿真比较后由组织者批准。
6. 执行读取命令回执；封路、水源失效或人工改派影响后续步骤时，提出复核或让出控制。
7. 结束后冻结训练档案；经验草稿经审核发布后，才可用于后续检索。

## 三类依据

| 依据 | 来源 | 用途 |
| --- | --- | --- |
| 专业与社区资料 | 已发布文档、设备说明和社区预案 | 来源、适用性与操作解释 |
| 现场事实 | 服务端当前或历史快照 | 人员、道路、烟气、资源、任务、场次时刻与版本 |
| 工具结果 | 路线、资源、正式仿真和任务回执 | 合法性、有限时域比较和真实执行结果 |

内置资料位于 [fire_knowledge.json](../../backend/app/data/fire_knowledge.json)，来源链接与发布者随资料保存；项目自行编写的训练说明与官方来源摘要分别标识。启动按固定 ID 导入，不覆盖用户资料或旧引用。当前资料数应以文件与知识页面为准，不以旧阶段截图为准。

## 关键词与可选语义检索

默认关键词检索无需外部密钥；切分、排序和固定题集分别位于 `knowledge_ingestion.py`、`knowledge_ranking.py`、`backend/evaluation/`。可选语义服务独立配置：

```dotenv
KNOWLEDGE_EMBEDDING_URL=https://<provider>/v1/embeddings
KNOWLEDGE_EMBEDDING_MODEL=<available-model>
KNOWLEDGE_EMBEDDING_KEY=<local-secret>
```

先授权发布资料建立索引，再授权查询使用语义通道。索引绑定端点及模型，向量维度和有限数值经过校验；批次失败不覆盖原索引。未配置、失效或无有效索引时，页面说明回退原因并使用关键词结果。聊天模型配置不能代替 Embedding 配置。

## 一个协调器、四类能力

| 能力 | 当前职责 |
| --- | --- |
| 现场感知 | 查询场次版本、目标人员、风险、任务、资源与阻塞 |
| 方案规划 | 解析目标约束、检索依据、调用路线与仿真工具比较 |
| 资源协同 | 检查护送员、机器人、车辆、门控的占用、依赖与到位条件 |
| 执行监督 | 核对命令台账、异常影响、计划修订、真实到场与清点 |

四类能力属于同一协调器，并非四个独立语言模型。默认本地解析和确定性规划可运行；授权模型后可做目标理解、只读工具推荐及解释。模型不能自行改写评分、到场、证据或批准执行。

计划保存批准版本、稳定命令编号、资源归属与任务依赖。技术重试复用命令编号；业务调整产生新版本。人工改派让旧计划交还控制，已受理行程保留。广播须真实到位，护送须真实会合；责任人的现场核验和集合清点不能由规划文本代签。

## 预测与经验的含义

候选预演只描述注明时域内的模型结果，预估分不等于最终成绩。逐栋时序估算独立显示，尚不含全部队列、护送接近与人工核验。经验检索比较场景、人数、模型和条件差异；单次训练档案不直接当作策略收益证据。
