# 领域术语

| 术语 | 当前项目中的含义 |
| --- | --- |
| 冻结世界 | 新场次保存的地图、参数、人口、任务、资源及规则输入，历史不按新模板重造 |
| 权威状态 | 服务端按事件及冻结输入产生的人员、风险、任务和资源状态 |
| 命令 | 经鉴权、幂等和领域规则校验的动作；点击按钮不等于命令完成 |
| 事件 | 已发生动作或结果的持久化证据，具有场次序号和仿真时刻 |
| 连续疏散空间 | 房间、门洞、走廊、楼梯、楼门、室外与集合点构成的可通行图 |
| 暴露 | 本模型的累计烟气风险量，不代表真实毒理剂量 |
| 到场 | 人员实际到集合点的仿真状态 |
| 清点 | 责任人对已到场人员提交的核验；不能由到场状态自动代签 |
| 护送 | 值守员先接近并会合，再与重点居民同行撤离 |
| 预演 | 未执行方案在注明未来时域内的模型计算 |
| 时序估算 | 按当前行程与依赖计算的时间估计，未覆盖全部动态等待 |
| 计划修订 | 从当前位置调整未完成行动，保留暴露、电量、证据与已受理行程 |
| 反事实分支 | 从相同历史起点执行另一决策的独立场次，原始结果不变 |
| RAG | 在当前权限和适用范围内检索已发布资料，再用于有来源的解释或规划 |
| 训练档案 | 结束事务冻结的人员、任务、设备、评分及事件摘要 |
| 经验草稿 | 根据原始观察生成、等待审核的可编辑资料；不自动进入知识检索 |
