# 场景助手工作区

本文件说明助手局部职责；全局令牌、正文16px/辅助14px、触控尺寸和定位规则由 [DESIGN.md](../../DESIGN.md) 统一定义。

## 两种视图

- **场景对话**：读取当前或历史快照，提供离线规则解读或经授权的模型回答，附数据时刻与依据。导航到人员、任务或回放；对话回答不直接执行命令。
- **目标计划**：解析人员范围，比较仿真候选，经人工批准后调用统一命令服务，监督疏散、护送、机器人、门控、责任任务和集合清点。

当前采用一个协调器内的现场感知、方案规划、资源协同、执行监督四类能力。离线解析与模型解析明确标识；不把四个状态标签称为四个独立大模型智能体。

## 交互

生成、重算方案时请求服务端暂停审阅；批准后恢复现场。路线预览、批准版本、资源归属、任务等待原因与结果依据在同一工作区呈现。案例责任任务直接进入原任务抽屉，集合核验进入统一清点抽屉；不叠加第二个业务窗口。

历史现场保持只读，旧回答标明数据时刻。房门等动作以服务端安全条件与领域事件为准，不能把解释、预演或按钮点击当作实际完成。

## 布局归属

- `SceneAssistant.vue` 管理对话与计划视图，`AgentPlanWorkspace.vue` 管理计划正文。
- `director-layout.css` 管理导演台壳层位置，`assistant.css` 管理助手内容，阅读令牌管理字号。
- 标题、正文滚动区和输入区各自保持稳定；窄屏与短屏通过内部滚动和视图收纳适配。
- 具体尺寸以代码与全局规范为准，本文不再重复早期绝对定位数值。

早期局部尺寸和只读助手说明已合并到 [历史页面记录](../history/ui-evolution.md)。当前实现与自审见 [演练修复记录](../2026-10-23-演练操作修复与智能体能力核对.md)。
