# 早期页面迭代记录（已合并）

以下为2026年9月早期页面布局的历史记录，当前页面结构和规范以根目录 [DESIGN.md](../../DESIGN.md)、[操作指南](../../使用指南.md) 及 [当前架构](../architecture/README.md) 为准。

## 登录与首页

早期版本先采用左右分栏登录、项目列表与常驻示例栏，随后取消单项目下的无效大留白，将社区、示例、说明和个人中心按任务拆分。账号信息移入独立工作区，侧栏采用固定轨道，窄屏转换为顶部导航。当前版本已经进一步采用演练首页、场景准备、复盘和社区管理的导航，不沿用早期“左右照片/表单”或四页布局作为验收标准。

早期布局验收覆盖320～1920px的若干视口、登录路由、搜索筛选及个人入口；这些结果仅描述当时版本，不作为当前版全流程通过的证明。

## 导演台与助手

多份布局修复记录的共同结论已收敛进当前设计规范：壳层定位由 `frontend/src/director-layout.css` 统一管理；教练、助手、任务和对象详情按上下文切换；内部滚动区域为时间线和入口预留空间。助手采用标题、可滚动正文、输入区的分区布局，模型详情渐进展开，不能挤占消息或任务正文。

当前助手同时包含场景对话与目标计划。早期“助手完全只读、不能执行”的整体描述已过时：场景对话仍用于解释和导航，目标计划经人工批准后调用领域工具。详见 [智能体能力核对](../2026-10-23-演练操作修复与智能体能力核对.md)。
