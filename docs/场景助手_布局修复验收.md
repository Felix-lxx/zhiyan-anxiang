# 场景助手布局修复

问题：配置、授权长说明、常见问题和输入框都堆在底部，输入区最高占面板 65%，对话正文只剩窄条。

## 本轮调整

- 保留导演台深绿色样式；桌面面板宽度上限由 430px 增至 480px。
- 顶部固定场次与紧凑授权条。开关持续可见，不默认替用户授权。
- 模型详情、重新检查、完整授权说明在对话滚动区域按需展开，不改变输入区位置。
- 空态提供五个常见问题；发送后收起，底部保留常见问题入口。
- 输入框固定在底部；消息区为主要滚动区域，移除输入容器的双滚动和 65% 高度分配。
- 小高度屏幕压缩次要说明、标题和输入间距，保留模式开关及发送按钮。

`tmp/verify_model_activation.cjs` 使用真实本地配置状态，拦截聊天接口返回模拟答案，不调用外部模型。

通过：无横向溢出；配置条、消息区与输入区不相互覆盖；发送按钮在视口内；展开设置不压缩对话高度；授权开关仍控制请求的 use_model；配置重查不自动恢复已撤销授权；浏览器无脚本异常；生产构建通过。
