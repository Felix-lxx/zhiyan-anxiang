# 楼栋放行的空间呈现

本轮补齐 P2 的“等待楼栋三维标记”，并把智能体的放行批次接到实际楼栋定位。不改评分、移动、供水和任务完成规则。

## 状态来源与交互

`agent_execution.coordination_view` 在既有放行批次中增加楼栋 ID、名称、目标人数和实际到场人数。私有智能体实时投影随场次版本同步；前端只有在场次 ID 与来源版本一致、实时连接有效时显示现场标记。未批准计划、过期投影和历史回放不显示当前计划标记。

三维标记包括楼门入口环与屋顶状态牌，表达等待放行、正在撤离、受阻或已到集合点。标记属于注释层，不改变道路、门洞、碰撞或人物位置。相同状态复用纹理，状态变化与移除时释放资源；室内透视、居民视角和紧凑比较世界隐藏标记。标记代替该楼栋原有名称牌，投影相交的状态牌避让隐藏，入口环继续保留。

智能体原工作区的“楼栋放行进展”展示对应楼名和到场人数，点击定位会收起当前面板并将相机对准该楼栋；关闭、返回和其他操作仍沿用单工作区。定位动作不下达疏散或喷水指令。按钮正文 16px，操作高度至少 44px，可换行。
