# P2：三维火点选择与冻结

日期：2026-10-21

## 交付内容与入口

进入社区的「场景准备 → 火源与烟气」，点击三维中浅绿圈标出的充电棚，或通过「充电棚对象」列表选择。金色圈表示当前选择。更换后试算刷新火焰位置、风险和关联任务；视角保持不变，不因选点重新装载模型。

操作顺序：

1. 核对场景和关联底图，进入「火源与烟气」。
2. 点选合法充电棚，观察火点和风险预览；可撤销至最近保存的选择。
3. 保存参数，再进行校验、发布；修改已发布场景会派生新草稿。
4. 创建新场次。新场次冻结火源地址、位置及道路接入点；启动后机器人沿该场次路网前往选定火点复核。
5. 处置任务显示具体充电棚名称与位置；回放读取创建事件内的冻结世界。

本阶段开放充电棚对象选点。房间选点、厨房分区环境和室内任务属于 P3，未将厨房案例提前开放。若底图只有一个充电棚，就只有一个合法候选；可在地图编辑器补充实际对象后配置新场景。

## 数据与执行链

参数继续兼容 `fire_source_object_id`。保存时由服务端补充 `parameters.fire_source` 地址：`schema_version`、`source_type` 与 `location`；其中位置身份包含 `kind=object`、`object_id`、`community_version_id`。客户端不提供权威坐标。

`fire_sources.resolve_fire_source` 是保存、准备检查、预览和新世界捕获的共同解析入口。它验证对象身份、所属底图、类型和有限坐标范围。失效火点不再自动替换为第一个充电棚；错误可定位到准备页的火点字段。

`GET /scenes/{scene_id}/fire-sources` 读取场景绑定版本的合法候选，而不是直接借用社区当前底图对象。接口执行社区归属校验，不能读取他人场景。

世界捕获时生成 `world.fire_source`：在地址基础上冻结名称、实际位置 `position` 和道路接入位置 `access_position`。以下既有字段从该数据派生：

| 下游 | 来源与效果 |
| --- | --- |
| 环境风险 | `fire_origin = position`；火势、烟气与路段风险仍由既有规则计算 |
| 三维火焰与灯光 | 随服务端预览中的 `fire_origin` 原地更新，不重新加载整个社区 |
| 自动巡检 | `inspection_target = access_position`；任务事件记录具体对象身份与名称 |
| 断电任务 | 目标名称、对象编号和到位位置绑定所选充电棚 |
| 车辆与其他工具 | 继续读取冻结世界的火点与道路，不另造一份火点状态 |
| 回放 | 原样读取旧场次创建事件；不因场景改选或地图移动而重建历史 |

无需数据库迁移，也不重写已有冻结事件。旧世界没有 `fire_source` 时仍使用其原有 `fire_origin`、`inspection_target` 和任务数据。

## 页面实现

沿用浅色准备页、深色现场预览。点选说明是预览上方的普通文档流，不添加悬浮面板。参数栏保留键盘可操作的列表、就地撤销和读取失败重试。

- 使用对象编号命中三维模型、对象标签及选择圈，不依赖名称或屏幕位置猜测目标。
- 选择模式只在火源步骤启用；浏览预览不会发出道路封锁、机器人或居民领域命令。
- 请求取消与序号保护防止过期预览覆盖新选择。保存失败保留草稿；保存期间继续修改参数时，新修改不会被误标为已保存。
- 已保存、未保存试算、更新中和预览失败分别提示；失败时明确标识仍显示上一次预览。
- 预览摘要固定四列；短屏保留三维高度，页面可滚动；移动端按预览、参数的顺序展示。

## 针对性验证

后端检查覆盖不同火点的预览、保存恢复、发布、新场次冻结、巡检路线、任务目标和旧回放；同时检查删除对象、错误对象类型、错误坐标和伪造地址。使用隔离数据库，不改动用户社区。

浏览器使用真实生产 Vue / Three.js 组件和隔离数据，验证射线点选、列表同步、撤销、保存失败、保存恢复，以及 1440×900、1366×650、390×844 的布局。不是仅检查按钮存在。截图位于 `output/playwright/fire-source-selection/`，脚本为 `frontend/tests/fire-source-selection.e2e.mjs`。

## 自我拷问

- 点了火源，是否只改画面？不是。新场次巡检路径、任务目标和风险读取同一冻结火源。
- 旧底图的场景是否会混用当前地图？候选按场景绑定版本查询，保存再次验证所属版本。
- 非法火点是否会悄悄换成默认点？不会；保存、预览、发布和新场次均拒绝无效输入。
- 改火点是否会改写历史？不会；已创建场次始终使用自己的冻结世界。
- 保存失败是否丢掉操作？不会；保留当前草稿和失败提示，可继续修改或重试。
- 手机是否只能靠点击小模型操作？不是；同一个参数列表可用键盘和触控选择，与三维选择同步。
