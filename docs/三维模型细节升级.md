# 三维模型细节升级 · 2026-10-01

## 本轮实现

- 建筑：保留场景配置中的占地和层数，取消整楼压扁；近景增加窗框、防盗栏、阳台栏杆、空调外机与风扇、排水管、屋顶水箱、入口门把手。远景保留窗户和主体轮廓。
- 材质：离线、确定性的抹灰、沥青、铺装颜色与凹凸贴图；线性数据贴图和 sRGB 颜色贴图区分；使用 ACES 色调映射。
- 街道与设施：井盖与沟槽、充电棚金属屋面、充电设备与电动车细节、消防站卷帘门与标识、消火栓出水口与法兰螺栓、路边座椅与垃圾桶。新增街道家具通过道路和建筑占地检查后放置。
- 居民：关节人物、服装差异、重点人员识别、护送员反光条与安全帽。服装颜色不再随风险变色，风险和选中状态由脚下环与轨迹表示。新增近远景 LOD，紧凑模式不再抽样隐藏居民。
- 动作：按实际坐标变化摆臂迈步；排队停步、拥堵缩小步幅、暴露后身体前倾；机器人四轮随位移转动，朝向随移动方向变化。显示插值仅用于平滑服务端位置，不改变决策或评分。
- 烟火：两个实例化网格承载火焰与烟气，软边着色、火焰收尖、按风向漂移。粒子由演练时间确定，可随历史快照复现；火势为零时隐藏粒子并熄灭火光。
- 楼内：从既有空间图生成走道、台阶、扶手、楼板和开放式隔墙及门框；房间、楼梯、人物、路线使用同一个高度转换。
- 画质：导演台视角栏提供精细、均衡、流畅三档，调整像素比、阴影、有效路灯数量、模型 LOD 距离和粒子数；运行时显示实测帧率，暂停时按需绘制。

## 数据兼容

后端旧空间图用 1.92 表示楼层间隔，旧建筑整体缩放也与此关联。本轮没有修改已经冻结的场次、路径成本、仿真速度或数据库。

渲染层 `displayHeight` 将第一层室内地面映射到 0.18，之后每层增加 3.2；地面高度保持 0。道路高亮、路线等离地偏移在转换后单独增加，避免落入地面。所有三维消费者共用 DigitalTwinArena，因此场景预览、导演台、回放和平行世界共用模型工厂。

## 验收

- 自动化：楼层/人物净高、未压缩建筑、动作停止、模型尺度稳定、机器人四轮、烟火确定性、画质粒子数量、零火势熄灭。
- 浏览器：已在本地真实 API 场次中检查导演台、楼内剖面、机器人跟随、居民第一视角、画质切换及 390px 窄屏；检查 WebGL 着色器和运行时错误。
- 场次：`三维细节验收 2026-10-01`，与已有场次分开。框选 18 人、预演北门路线并通过确认操作下达疏散指令。

## 自我拷问及边界

模型是否只是外观替换？人物动作读取真实坐标变化，轮子读取真实位移，风险读取真实状态，楼内几何读取空间图；没有另造展示用疏散数据。

是否等同于实测小区和工程级火灾仿真？不是。当前仍是可离线运行的参数化训练模型；楼内布局由训练空间图推导，烟火是视觉表现，不能据此宣称精确热流、烟气 CFD 或真实建筑测绘。车辆沿用已有静态素材，没有新增消防车救援运动或伪造运行状态。

画质是否保证所有设备固定帧率？不保证。三档可手动切换，本轮未实现自动基准测试、动态分辨率或基于 GPU 负载自动降档。实例化粒子和 LOD 是已实现的降载措施。
