# 首页布局修复与自检

## 本轮问题

- 单个社区项目与常驻右栏形成三列布局，中间出现大面积无意义留白。
- 左侧栏随页面滚动的稳定性不足，账号区只有退出图标，没有可理解的个人中心入口。
- 768px 宽度下训练内容存在越界风险。

## 已实现

- 首页改为四个独立工作区：社区项目、示例训练、使用说明和个人中心；URL 同步当前页面并支持浏览器前进、后退。
- 桌面侧栏改为视口固定轨道；导航区可独立容纳内容，账号区稳定停靠底部。
- 个人中心迁移到主内容区，使用真实登录账号和角色显示权限范围，支持退出，不再覆盖导航或业务内容。
- 示例训练与使用说明使用各自的任务布局；700px 以下切换为顶部导航和手机单列。

## 自我拷问

1. **是否只是移动了卡片？** 否。页面拓扑由“列表/空白/右栏”改为四个按任务切换的工作区，项目列表不再同时承载教学和个人信息。
2. **侧栏是否真的不会上下脱离？** 浏览器在 1440×720 页面滚动到底部后检查，侧栏 `y=0` 且高度等于视口。
3. **个人中心是否只是按钮外壳？** 不是。独立页面读取当前会话账号与角色，角色决定权限说明，退出会清除令牌并返回登录页；没有冒充未实现的资料编辑功能。
4. **响应式是否靠视觉猜测？** 不是。320、390、768、1024、1440、1920px 均执行控件与文本边界检查；首轮发现 768px 训练卡片越界后改为单列，复测通过。
5. **是否破坏原功能？** 搜索、状态筛选、创建表单、示例失败恢复、地图/演练路由、刷新恢复登录与退出均通过回归；失败测试使用网络拦截，没有写入验收社区。

## 技能

通过官方技能安装器检索后，已安装 `playwright-interactive` 技能（下一轮对话生效）；本轮使用现有 `playwright` 与 Impeccable 完成真实浏览器交互回归和布局判断。
