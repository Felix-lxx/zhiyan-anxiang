# 登录与首页界面规范

范围：`App.vue` 的登录区、`ProjectHome.vue` 和 `entry.css`。模式：Operate。沿用现有 DESIGN.md 的品牌绿、浅色编辑表面和 SVG 图标；不把本轮布局扩展到三维导演台。

## 布局

- 登录：桌面左表单、右社区摄影，边距 20px；表单最大宽度 380px。账号在 DOM 与键盘顺序中均先于参考照片链接。
- 登录窄屏：700px 以下改为单列，先显示登录与服务状态，摄影放在后方。摄影与实际训练截图不可混淆。
- 首页：216px 固定左导航与最大 1360px 的内容工作区。“社区项目、示例训练、使用说明、个人中心”切换独立页面，不使用常驻第三列撑开空白。
- 1150px 以下左导航缩至 184px，工作区边距缩至 24px；700px 以下导航改为顶部横排，内容边距 20px。
- 项目真实数量很少时保持克制，不填造假的统计、最近活动或重复入口。

## 控件与反馈

- 颜色使用 `styles/tokens.css` 的品牌、表面、文本和边界令牌，页面布局由 `entry.css` 管理，不在业务组件中再叠加另一套位置规则。
- 主按钮使用品牌绿；辅助操作使用描边或文字链接。主要按钮与图标按钮最小高度 44px，手机输入字号 16px。
- 搜索与状态筛选仅作用于后端返回的真实项目；无结果时提供清除筛选。
- 新建为就地表单，打开聚焦社区名称，关闭后聚焦新建入口；失败保留表单内容，不假装保存成功。
- 导航入口使用正式 URL 状态切换，目标标题会获得焦点，浏览器前进、后退可恢复页面。
- 侧栏账号区进入独立个人中心页面，展示当前账号、后端返回的角色与对应权限说明，并提供退出工作空间操作；不再以浮层覆盖业务内容，也不伪造头像上传、通知或账户编辑能力。
- 所有异步动作保留忙碌、失败与重试反馈；不可达服务禁用登录，重新检查后恢复。
- 键盘焦点、选中文字、加载/错误文案与减弱动效偏好均有处理。状态有文字，不仅靠颜色。
