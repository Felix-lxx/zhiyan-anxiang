## 视觉规格

沿用 tokens.css，新增图册专用尺寸和字级。浅色暖白 #f5f2ec，深色现场 #071a17，深绿 #163e32，橙 #c44820。正文 14–16px，标题 28–38px；登录标题用宋体字形。桌面首页侧栏 230px（图稿占宽 13.75%），顶栏 66px，内容横向 32px。场景准备为步骤 176px + 自适应三维 + 属性 350px。导演台顶栏 76px、时间轴 116px，浮层不得侵占时间轴。

## 验收清单

- 每页：截图、设计稿对比、移动端/窄桌面溢出检查。
- 登录：导演验证、密码显隐、加入码解析、错误恢复。
- 首页：场景选择、进入演练、最近记录、社区管理、导航。
- 场景：参数变更、同源预览、保存、校验、发布、脏数据保护。
- 导演：对象选择、路线预演、确认执行、暂停恢复、抽屉、手机邀请。
- 参演：登记、接受/到达/提交、异常回执、清点、断线恢复。
- 复盘：拖动时刻、选择事件、评分证据、分支创建、双世界、报告。
- 离线和无数据场景必须给出可恢复路径；不以静态背景代替真实三维。

## 资源约束

图册未提供可交互的高精度模型。静态封面另生成无文字社区资产，实时页面继续使用真实 Three.js 模型和仿真坐标；模型画质与图稿的离线渲染存在独立差距，必须如实披露。

### 尚未达到图册的部分

1. 三维建筑、居民、植被及火烟是现有规则仿真的低多边形资产，不是图册写实材质的数字孪生。需要匹配真实坐标和楼内连接的高精度模型/材质资产，不能拿静态封面替代可交互现场。
2. 参演页使用真实路网矢量平面图，没有图册中的卫星底图、GPS 路线和肖像。当前没有位置授权/地图服务/人物资料接口，未伪造定位或居民年龄、病史。
3. 现场证据为文字，未实现照片上传与视频证据；导出为现有 JSON 格式，不是 PDF。
4. 字体沿本机宋体/黑体回退链，标识沿用项目 SVG，没有图册原始字体与 Logo 矢量资源，细节不会完全一致。
5. 旧场景若未创建可执行责任任务，参演端会如实显示任务为空。需要在场景准备配置并执行决策选项后新建场次，旧的冻结场次不会被自动篡改。

### 自我拷问

- 是否只做按钮？否，浏览器点击确认封路后，服务端路段状态改变；参演任务证据持久化；复盘创建了不同 ID 的真实分支；报告可下载。
- 是否证明布局不会挡操作？验收实际发现一次时间线拦截点击，修复 Teleport 浮层的固定位置、滚动边界和层级后，同一流程通过。
- 是否可以宣称六页与图册一比一完成？不能。布局与主要交互已落地，上述三维资产、地图/人物资料和多媒体证据仍与图稿不同。
- 是否为了凑齐演示编造数据？没有。参与人数、得分、时间、任务来自 API；空任务状态明确解释，静态封面不冒充实景。
