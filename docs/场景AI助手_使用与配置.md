# 安巷教练 · 场景 AI 助手

## 从哪里打开

登录 → 社区项目「演练中心」→ 右侧工具列「AI 助手」。该助手绑定当前场次；切换场次重新开始对话。关闭再打开保留本场对话，离开页面或刷新后清除，不写入浏览器持久存储。

可以直接问：现在下一步应该做什么、谁还没到集合点、机器人为什么没动、道路拥堵如何处理、如何从关键决定前重做。回答下方有本轮时间与数据依据，并可跳到任务、清点、重做或定位居民。历史模型不具备的新功能会明确提示升级，而非显示失效入口。

本轮细节优化：可直接点名询问具体居民，完整名单匹配优先于前 16 条摘要；长回答从开头展示，点击 [S1] 等编号展开对应依据。现场推进或回放时间变化时可按新快照重答。常见问题支持展开，清空需要确认，发送失败可一键重试；中文输入法确认不会误发送。手机支持焦点循环及小可视高度布局，但桌面模拟视口测试不等同于真机软键盘认证。

## 两种模式，不混淆

- **离线场景解读**：无需密钥即可读取真实规则快照；有限意图匹配，不是语言模型，无法可靠回答任意开放问题。
- **模型问答**：管理员配置模型后，在输入框上方勾选「启用大模型问答」，再点击「发送给模型」。勾选代表允许发送本场精简摘要、问题和最近对话；刷新或切换场次需重新授权。未勾选时按钮明确显示「离线解读」。

界面中的“已配置”只表示配置齐备，不是连通测试结果。模型不可用、超时或返回异常时，本轮明确降级为离线解读。

每次重新打开助手会重新检查后端配置；也可点击「重新检查配置」。登录失效时提示重新登录，不再把认证失败混同于未配置。

DeepSeek V4 官方接口默认开启思考模式。本平台的短回答适配器对 `api.deepseek.com` 下的 `deepseek-v4-*` 显式使用 `thinking.type=disabled`，避免有限输出预算先被推理消耗而没有正文；其他厂商不附加此专有参数。参见 [官方思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 服务端配置

在项目根目录 `.env` 增加相应字段，保留已有数据库和登录配置。修改后重启当前后端进程。密钥不放前端，不提交到版本库，不发到对话里。

兼容对话接口（例如管理员选用的 DeepSeek 接口）：

```dotenv
ASSISTANT_PROVIDER=compatible
ASSISTANT_BASE_URL=https://api.deepseek.com
ASSISTANT_MODEL=填写所选服务实际提供的模型名称
ASSISTANT_API_KEY=填写本地密钥
ASSISTANT_TIMEOUT_SECONDS=40
```

基础 URL 不包含 `/chat/completions`，服务端自动追加。仅允许 HTTPS，不接受 URL 中的账号、密码、查询参数或重定向。接口按 [DeepSeek Chat Completions 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/) 约定实现；模型名称需以账户当前可用值为准，不预设型号。

本机 Ollama（需管理员另行安装并准备模型，本轮未安装/下载模型）：

```dotenv
ASSISTANT_PROVIDER=ollama
ASSISTANT_BASE_URL=http://127.0.0.1:11434
ASSISTANT_MODEL=填写本机已有模型名称
ASSISTANT_API_KEY=
ASSISTANT_TIMEOUT_SECONDS=40
```

基础 URL 不包含 `/api/chat`，本地服务按 [Ollama Chat 官方文档](https://docs.ollama.com/api/chat) 接入。只有本机 Ollama 允许 HTTP；远程地址要求 HTTPS。

## 数据与权限边界

- 每次提问由后端校验社区归属，读取当前场次或指定历史时刻。请求端不能伪造场景数据、得分或系统消息。
- 问答不推进仿真、不创建事件、不改变道路/居民/机器人/评分；跳转按钮只做导航，处置仍由原页面确认。
- 回放上下文不包含未来事件与当前评分。历史模型未提供核验数据时，不把缺失字段冒充真实清点结果。
- 外部模型接收精简道路/任务/居民状态、最近事件类型，以及用户问题与最多 12 条历史消息。场次名称、居民姓名、搜索负责人、参演身份凭证、邀请码与原始事件 payload 不随新快照发送。用户在问题或历史对话主动写入的信息仍可能被发送，请勿粘贴隐私/密钥。
- 居民明细最多 16 条，优先失联、未到、重点和拥堵人员；回答明确节选，完整名单请打开清点区。模型不具备浏览互联网、控制设备或调用处置工具的能力。
- AI 可能误解数据；规则结果也不是实测 CFD 或现实安全认证。本功能用于模拟训练，不是实际火灾现场指挥工具。

## 验证范围

后端测试覆盖归属权限、空白/超长/伪系统消息、只读性、历史快照、离线多意图、授权后才调用、失败不泄露密钥、兼容接口/Ollama 请求与响应协议。模型协议测试采用模拟 HTTP 服务，并非真实供应商调用。

浏览器脚本 `tmp/verify_assistant.cjs` 检查离线真实接口、依据展开、版本对应导航、关闭重开、手机边界、失败重试、键盘焦点。原项目数据与历史场次保留。
