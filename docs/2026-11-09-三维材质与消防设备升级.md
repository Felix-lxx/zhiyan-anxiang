# 三维材质与消防设备升级

日期：2026-11-09。

## 资源选择与落地

搜索并核对了 Poly Haven、Kenney、Khronos glTF Sample Assets 与 GitHub 的公开资源。项目已有的 Kenney 骨骼人物、车辆、厨具和 Husky 部件继续使用，保留其原许可文件。新增落地的是 Poly Haven 官方 CC0 的道路、铺地、墙面三组 PBR 材质，各包含颜色、OpenGL 法线和粗糙度图，共九张 1K JPEG，约 6.67 MB。

来源与许可见 `frontend/public/assets/surfaces/SOURCES.md`。`scripts/fetch-surface-assets.ps1` 只下载这九个选定文件，并逐一与官方 API 的 MD5 核对。没有下载整个模型库或引入外部运行时 CDN。

## 实现

- `sceneMaterials.ts` 保留程序化占位材质，实拍纹理解码后更新；颜色使用 sRGB，法线和粗糙度保持线性。低画质关闭法线和粗糙度贴图着色。加载完成使暂停画面重绘；销毁后忽略迟到结果并释放 GPU 资源。
- 浏览器发现占位图与 1K 图尺寸不一致引起 WebGL 上传错误，已在替换像素前释放原 GPU 纹理分配。道路延续已有世界坐标 UV，路口与路段共享颜色与贴图比例。
- 新增 `firetruckEquipment.ts`：泵组仪表、黄铜接头、阀轮、水带卷和可转向车顶水炮；几何限定在原 2.45 × 6.2 米车身平面范围。喷水读取已受理处置目标，水柱来自炮口，水带连接实际进水接口。轻量模型切换为详细模型时，接口变化会重建水效。
- 厨房增加水壶、壶盖、把手、砧板、刀具和调料瓶，均位于服务器已校验的厨台范围内。没有把装饰物放进房间通行区。
- 机器人增加密封维修盖、通风槽、紧固件和急停帽；帽体属于模型细节，不代表新增远程急停控制。人物保留原骨骼、步态和脚部贴地，只补充材质差异。
- 水带使用受路面高度约束的曲线，不仅校验控制点，还约束曲线中段；管体半径纳入离地净距，避免样条下冲产生陷地。
- 供水升级后，新动作沿服务端绕楼路径逐段绘制，保留净距与拐角，接入实际消火栓出水口和车辆泵口。资源、故障、车辆设施避让和界面验收见 [P2 交付记录](2026-11-09-P2-充电棚放行编排.md)。
- 楼栋材质副本登记到同一画质管理器，共享贴图并同步关闭或恢复法线、粗糙度贴图；退出场景释放副本。室内材质管理器同步接入画质与异步重绘回调，避免厨房仍用高画质或暂停画面停留在占位材质。
